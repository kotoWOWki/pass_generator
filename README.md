# Password Generator
Криптостойкий генератор паролей с гарантией состава символов.

Пример: 8-syn(1yc=bQwYnPl3

- Используется secrets, а не random. 
- Гарантируется по одному символу из каждой категории (строчные, заглавные, цифры, спецсимволы)
- Остальные символы - из полного алфавита
- Перемешивание через `secrets.SystemRandom`
